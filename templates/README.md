# 视频总结模板

## 用途

此模板用于生成视频总结的 Markdown 文档，由 `analyze-subtitles-ai.py` 脚本调用。

## 模板变量

| 变量 | 说明 | 来源 |
|------|------|------|
| `{视频标题}` | 视频标题 | 元数据 |
| `{标签 1}` ~ `{标签 5}` | 标签列表（5 个） | 四层标签策略 |
| `{UP 主名称}` | UP 主/作者名称 | 元数据 |
| `{封面 URL}` | 封面图 URL（OSS 上传后） | OSS 上传 |
| `{100-200 字概述}` | AI 生成的笔记概述 | AI 分析 |
| `{视频来源}` | 平台来源（Bilibili/YouTube/小红书/抖音） | URL 推断 |
| `{视频 URL}` | 视频原始链接 | 元数据 |
| `{视频时长}` | 视频时长（MM:SS） | 元数据 |
| `{发布日期}` | 发布日期 | 元数据 |
| `{播放量}` | 播放次数 | 元数据 |
| `{点赞数}` | 点赞次数 | 元数据 |
| `{评论数}` | 评论次数 | 元数据 |
| `{最终归纳段落}` | AI 生成的最终总结 | AI 分析 |
| `{生成日期}` | 文档生成时间 | 自动生成 |

以下区块由 Python 代码通过正则替换（非模板变量）：

| 区块 | 说明 | 来源 |
|------|------|------|
| `## 🎯 核心要点` | emoji + 要点标题 + 描述 + 时间戳 | AI 分析 → `format_key_points()` |
| `## 🎬 视频章节` | 章节标题 + 时间轴 + 截图 | AI 分析 → `format_video_chapters()` |
| `## 📚 关键概念` | 2 列表格：概念 + 解释 + 时间戳 | AI 分析 → `format_concepts()` |
| `## ⚠️ 注意事项` | 列表：注意事项 + 时间戳 | AI 分析 → `format_warnings()` |

## 修改模板

直接编辑 `summary.md` 文件即可修改输出格式。

**示例：添加新章节**

```markdown
## 📚 关键概念

{概念占位符}

## 🆕 新增章节

这里是新章节内容...

```

## 测试模板修改

```bash
# 处理一个视频测试新模板
./scripts/video-summarize.sh "视频 URL" /tmp/test-output

# 查看生成的总结
cat /tmp/test-output/summary.md
```

## 注意事项

1. **保留变量名** - `{xxx}` 格式的变量不要删除，否则对应内容不会显示
2. **Markdown 格式** - 保持标准 Markdown 语法，确保 Notion 兼容
3. **区块替换** - 核心要点/视频章节/关键概念/注意事项四个区块由 Python 正则替换，不要修改区块标题
4. **变量位置** - 变量可以放在模板任意位置，按逻辑组织即可
