## 3️⃣ 跨平台分支逻辑检查

### ✅ 平台识别逻辑（`video-summarize.sh`）

```bash
# 平台提取函数（第 87-125 行）
extract_platform() {
    local url="$1"
    
    # B 站
    if [[ "$url" =~ (bilibili\.com|b23\.tv) ]]; then
        echo "bilibili"
    # 小红书
    elif [[ "$url" =~ (xiaohongshu\.com|xhslink\.com) ]]; then
        echo "xiaohongshu"
    # 抖音
    elif [[ "$url" =~ (douyin\.com|iesdouyin.com) ]]; then
        echo "douyin"
    # YouTube
    elif [[ "$url" =~ (youtube\.com|youtu\.be) ]]; then
        echo "youtube"
    # 微信视频号
    elif [[ "$url" =~ (channels\.weixin\.qq\.com) ]]; then
        echo "wxvideo"
    fi
}
```

**评估**: ✅ 逻辑清晰，正则匹配准确
